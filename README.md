# Dead Shows Archive

Explore Grateful Dead recordings, songs, personnel, and eras.

## Run locally

Requires Python 3.12+ and Node.js 22+.

```sh
npm run build
npm test
npm run dev
```

Open http://127.0.0.1:4173. The static site is built into `dist/`.

Recording evidence can be incomplete; ratings belong to recordings, and personnel filters describe membership windows.

An independent fan project. No audio is hosted. See [sources and credits](docs/SOURCES.md).
